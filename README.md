# 取名台 · 一字见心

以名为契 —— 融合八字、五行、音韵、卦象的智能中文取名工具。

基于 **SQLite 姓名数据库 + 多维评分引擎**，根据生辰八字、姓氏、性别等要素生成寓意深远、音韵和谐的中文名字。

---

## ✨ 功能

### 核心取名
- **八字喜用神** — 根据出生日期计算四柱八字，匹配五行喜用神/忌神
- **多维评分** — 八字(40%) + 经典文化(20%) + 音韵声调(20%) + 字义内涵(12%) + 周易卦象(8%)，权重可自定义
- **风格选择** — 优雅、大气、罕见三种取名倾向
- **性别适配** — 男/女/不限，按性别倾向筛选汉字
- **拼音标注** — 所有名字自动标注拼音

### 传统文化
- **生辰八字** — 公历/农历互转，自动排出八字四柱与五行能量
- **三才五格** — 姓名笔画数理分析（天格、人格、地格、外格、总格）
- **周易卦象** — 姓名笔画起卦，按六十四卦吉凶评分
- **五行属性** — 汉字五行归属查询与匹配
- **生肖适配** — 输入出生年份生肖，推荐宜用/忌用汉字偏旁
- **81 数理** — 姓名笔画吉凶数理查询
- **拆字分解** — 汉字字形拆分（偏旁部首）
- **大衍之数** — 大衍筮法占卜

### 特色功能
- **⏎ 经典出处** — 名字汉字出自《诗经》《楚辞》《全唐诗》等典籍时自动标注出处
- **⏎ 历史同名** — 生成结果中匹配历史同名人物（含朝代、身份）
- **⏎ 名字详情** — 点击名字展开详情面板，展示每个汉字的字义评分、五行、拆字、引用来源
- **拼音声调** — 音韵流畅度评分，声母韵母声调综合评判
- **语料验证** — 名字在真实语料中出现过的自动标记"语料出现"

### 界面
- **三套主题** — 墨韵（宣纸棕红）、青瓷（天青翠色）、朱砂（红墙金线），一键切换
- **权重面板** — 拖拽滑块自定义各评分维度的权重
- **分页浏览** — 结果分页展示，每次生成大量候选
- **响应式设计** — 适配桌面端

## 🚀 快速开始

### 环境要求
- Node.js >= 18
- npm 或 pnpm

### 安装与运行

```bash
cd quick-app
npm install
node api.mjs
```

访问 http://localhost:5177

> 数据库文件 `quick-app/db/names.db` 由 Git LFS 管理，克隆后需执行 `git lfs pull` 下载。

## 🧠 评分维度

| 维度 | 默认权重 | 说明 |
|------|----------|------|
| 八字喜用神 | 40% | 基础 60 分，命中喜用神 +20 分/字，落入忌神 -20 分/字 |
| 经典文化 | 20% | 两字均有典籍出处 = 100 分，单字有出处 = 80 分 |
| 音韵声调 | 20% | 读音流畅、声调平仄、声韵母差异综合评分 |
| 字义内涵 | 12% | 字义评分(Valence) ×10 + 温暖度 ×5 + 能力感 ×5 |
| 周易卦象 | 8% | 姓名笔画起卦，按吉凶得分 |

## 🛣️ API 接口

| 接口 | 方法 | 说明 |

| `/api/generate` | POST | 生成名字（姓氏、性别、风格、生辰、出生地等参数） |

| `/api/chaizi` | GET | 拆字分解 |
| `/api/yinyun` | GET | 音韵评分 |
| `/api/scoring` | GET | 评分规则与默认权重 |
| `/api/dayan` | GET | 大衍筮法 |
| `/api/health` | GET | 服务健康检查 |

## 🖥️ 技术栈

- **后端** — Node.js + Express 5 + better-sqlite3
- **前端** — 原生 HTML/CSS/JS（无框架，单页应用）
- **数据库** — SQLite（约 202 MB，包含 46 万+ 诗文引用、36 万+ 历史人名、15 万+ 语料姓名）
- **工具** — Git LFS（大文件管理）、OpenCC（简繁转换）
